# DULAT CODE — форма записи на собеседование

Форма берёт свободное время из Google Sheets и записывает ФИО кандидата в таблицу.
Занятое время сразу пропадает из формы, а двойная запись на один слот невозможна:
перед записью скрипт повторно проверяет ячейку под блокировкой (`LockService`).

## Структура таблицы (лист «Слоты»)

| A: Время | B: ФИО | C: Дата записи |
|----------|--------|----------------|
| 11:30    |        |                |
| 11:40    | Иванов Иван | 24.09.2026 … |

- Время добавляете вы, по одному слоту на строку.
- Пустая колонка B = слот свободен.
- Чтобы освободить слот, очистите B и C в этой строке.

## Настройка

1. Создайте Google Таблицу.
2. **Расширения → Apps Script**, вставьте содержимое `apps-script/Code.gs`, сохраните.
3. В редакторе выберите функцию `setupSheet` → **Выполнить** → разрешите доступ.
   Появится лист «Слоты» с заголовками и тестовым временем.
4. **Развернуть → Новое развертывание** → тип «Веб-приложение»:
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
5. Скопируйте URL (заканчивается на `/exec`) и вставьте в `API_URL` в `app.js`.
6. Откройте `index.html` в браузере.

## Важно

- После **любых** изменений в `Code.gs` нужно обновить развертывание:
  **Развернуть → Управление развертываниями → ✏️ → Версия: «Новая версия»**.
  Иначе будет работать старый код. URL при этом не меняется.
- Колонка «Время» должна быть в текстовом формате (`setupSheet` делает это сам).
  Иначе Google превратит `11:30` в дату.
- `ONE_BOOKING_PER_NAME = true` в `Code.gs` запрещает одному ФИО занимать несколько слотов.
  Поставьте `false`, если это не нужно.
